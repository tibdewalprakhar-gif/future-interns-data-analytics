# Marketing Funnel and Conversion Performance Analysis

## Objective
Analyze marketing campaign outcomes and conversion performance, comparing outcomes across customer segments or campaign characteristics.

## Dataset
One beginner-friendly option is the [UCI Bank Marketing dataset](https://archive.ics.uci.edu/dataset/222/bank+marketing).
Note: this dataset records campaign outcomes, not a complete website visitor → lead → customer funnel. Clearly define the funnel stages that the data actually supports.

## Tools
- Python (Pandas, Matplotlib)
- Power BI Desktop
- GitHub

## Workflow
1. Inspect and clean the dataset.
2. Define the conversion outcome using the dataset's actual fields.
3. Compare conversion rates across relevant segments.
4. Visualize the results in Power BI.
5. Write evidence-based recommendations.

## Important
Do not label campaign contacts as website visitors or leads unless the dataset explicitly represents those stages.
